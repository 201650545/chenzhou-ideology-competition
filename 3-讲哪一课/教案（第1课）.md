# 教案 · 第 1 课《最喜欢的课》

> 学科：心理健康 ｜ 年级：四年级上学期 ｜ 课时：1 课时（40 分钟，有生课堂）
> 教材：湘教版《心理健康》四年级上册 第 1 课（课本第 1–7 页）
> 课型：活动体验式（暖身 → 体验 → 分享 → 升华＋迁移）
> 执教：＿＿＿＿＿＿　｜　班级：＿＿＿＿＿＿　｜　日期：＿＿＿＿

## 一、教学目标

1. **认知**：能说出自己对各门课的喜爱程度，并从"有意思／有成就感／有人陪／有用处"等角度说明喜欢或不喜欢的原因。
2. **能力**：能从多个角度（对自己有用、对成长有价值、对将来做事有帮助）说出"不喜欢的课为什么还要学"，并为自己想出一个可行的办法。
3. **情感态度**：接纳自己有喜欢也有不喜欢；愿意用请教、交流、找方法的方式去接近不喜欢的课。
4. **课程思政**：体会每一门课的价值，初步树立**正确的学科观**；萌发"德智体美劳全面发展"的意识，同时愿意在自己最喜欢的事上多投入。

## 二、教学重难点

| | 内容 |
|---|---|
| **重点** | 觉察并说出自己对各门课的喜好及原因 |
| **难点** | 从"我喜欢什么"转向"每门课都有它的价值，不喜欢的也能找到门" |

## 三、教学准备

| 类别 | 清单 |
|---|---|
| 学具 | **学习单**（每人 1 张，A4 双面，正面／反面各一页）；彩笔（涂星用） |
| 教具 | 课件 PPT；黑板／板贴（用于环节四拼"缺一块"） |
| 环境 | 桌椅按小组围坐（4 人一组）；黑板预留左右两栏 |

**两种班额（同一张学习单，只是组织方式不同）**

| | 4 人班（本校／拍视频） | 30 人班（大学校） |
|---|---|---|
| 分组 | 全班一组，或 2 人一对 | 4 人一组，共 7–8 组 |
| 环节四认领 | **每人认领 1 门**（4 门都用上） | **每组认领 1 门**（7–8 门） |
| 黑板"缺一块" | 拼 4 块 | 拼 7–8 块 |

## 四、教学过程（40 分钟）

> 全课只发一次学习单、只翻一次面：**正面做环节一、三 → 翻面 → 反面做环节四、五、六**。

### 环节一 · 涂星自评（5 分钟）

- **教师活动**：发学习单；说明规则；巡视，不催促、不评价。
- **关键话术**：
  - "每个人心里，都有一张自己的课表。请把学习单翻到**正面**，给上面这 12 门课的星星涂色——**越喜欢的课，就涂得越多，最多 3 颗**。"
  - "不用想太久，第一感觉就好。"
- **学生活动**：给 12 门课涂 ☆。
- **学习单**：正面 · 环节一（我的课表星星榜）。
- **学生产出**：我的星星榜（前测）。
- **设计意图**：觉察起点；数据由学生自己产生，本身就是前测。

### 环节二 · 引出主题（3 分钟）

- **教师活动**：快速统计"涂满 3 颗星最多的课／星星最少的课"，写在黑板两侧；追问。
- **关键话术**：
  - "同一张课表，为什么大家的星星**不一样**？"
  - "喜欢不一样，很正常。今天我们就来聊聊——我们**喜欢的课**，和那些我们**不太喜欢的课**。"
- **学生活动**：口头回应。
- **设计意图**：点出"喜好不同很正常"，自然引出课题。

### 环节三 · 说理由（8 分钟）

- **教师活动**：请学生翻到正面下半栏，各写一条理由；组织同桌／小组互说；把理由归类板书（有意思／有成就感／有人陪／有用处；太难／没意思／用不上）。
- **关键话术**：
  - "喜欢，是因为什么？不喜欢，又是因为什么？我们试着把**'感觉'变成'理由'**。"
  - "先给你**最喜欢、涂满 3 颗星**的那门课写一条理由；再给**星星最少**的那门课写一条理由。"
- **学生活动**：写 2 条理由（正面·环节三）；互说。
- **学习单**：正面 · 环节三（说理由）。
- **学生产出**：两条理由（过程性证据）。
- **设计意图**：让喜好从"感觉"变成"理由"，为下面制造冲突打底。

### 环节四 · 假如没有这门课（12 分钟 · 高潮）

- **教师活动**：认领制 → 讨论 → 写在反面"环节四" → 汇报 → 把各组课程名／结论贴到黑板，拼成"缺一块"的图；追问"那为什么学校还要开这门课？"
- **认领方式**：4 人班**每人认领 1 门**；30 人班**每组认领 1 门**（尽量覆盖不同门类）。
- **关键话术**：
  - "假如，学校把这门课**拿掉**，整整**一个星期**都不上。我们的学习生活，会变成什么样？"
  - "来，把你们想到的写在反面'环节四'里。"
  - （汇报后追问）"我们刚刚说，没有它我们会……那——**为什么学校还要开这门课呢？**"
- **学生活动**：小组讨论、书写、汇报。
- **学习单**：反面 · 环节四（我认领的课 + 没有它会怎样）。
- **学生产出**：各组"没有它，我们会……"；黑板拼成"缺一块，就不完整"。
- **设计意图**：制造认知冲突；**五育的价值从学生嘴里自己长出来**，老师不喊口号。

### 环节五 · 我的两个小行动（7 分钟）

- **教师活动**：引导写两个行动；组织同桌互读。
- **关键话术**：
  - "① 那门你**不太喜欢**的课，给自己想一个**能试的办法**——比如换一种学法、问一次老师、找一个有意思的点。"
  - "② 你**最喜欢**的那门课，给自己安排**'多走一步'**——去做一件课堂之外、你真正想做的事。"
- **学生活动**：写两个小行动（反面·环节五）；同桌互读。
- **学习单**：反面 · 环节五（我的两个小行动）。
- **学生产出**：两个小行动（带回家）。
- **设计意图**：全面发展与个性发展**并行落地**。

### 环节六 · 反馈＋收口＋作业（5 分钟）

- **教师活动**：请学生写一句话反馈；**收口一句话**；布置亲子作业。
- **关键话术**：
  - （写）"今天这节课，你最大的发现是什么？用一句话写下来。"（反面·环节六）
  - （收口，语速放慢）"**每门课都好好学，是给我们打底子；但你最喜欢的那门，值得多花点时间——那可能是你将来最厉害的地方。**"
- **学生活动**：写"今天我最大的发现是＿＿"；把纸条交上来贴成一串。
- **学习单**：反面 · 环节六（今天我最大的发现）。
- **学生产出**：一句话反馈（后测）。
- **设计意图**：后测；升华；迁移到家庭。

## 五、板书设计

```
                    最喜欢的课

   我喜欢的                        我不喜欢的
   ┌──────────┐                 ┌──────────┐
   │ 有意思    │                 │ 太难      │
   │ 有成就感  │                 │ 没意思    │
   │ 有人陪    │                 │ 用不上    │
   │ 有用处    │                 │ 老师凶    │
   └──────────┘                 └──────────┘
            ↘                ↙
         没有它，我们会……
         （缺一块，就不完整）

   ★ 每门课都好好学＝打底子
   ★ 最喜欢的那门，值得多走一步
```

## 六、作业布置

- **课本第 6 页「亲子时光」**：问一问爸爸妈妈，他们学生时代最喜欢的课是什么、为什么喜欢；并**陪孩子在最喜欢的那门课上做一件拓展的事**（去书店／博物馆／美术馆等）。
- **课上产出带回家**：学习单反面的"我的两个小行动"。

## 七、上课要盯的三件事

1. **涂星别拖**：3 秒一门，最多统计两组数据（涂满 3 星最多的课、星星最少的课）。
2. **高潮给足时间**：环节四给足 12 分钟（讨论 3 分钟＋汇报 8 分钟），别被前段挤掉。
3. **追问要"追而不裁"**：老师只追问，不替学生下结论。

## 八、教学反思

> ⏳ **待试讲／录课后撰写。**
> 预设观察三点：① 高潮环节时间是否够；② 学生说"不喜欢"时会不会跑成吐槽、追问是否要调；③ 从涂星到讨论的过渡是否顺畅。
