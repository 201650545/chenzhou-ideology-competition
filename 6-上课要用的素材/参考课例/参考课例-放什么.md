# 其他应用材料

> 状态：持续收集。本目录是"可用素材库"，凡进库材料必须带**来源与可用性标注**。

## 分类建议

| 类别 | 内容 | 用途 |
|---|---|---|
| 课例参考 | 优秀心理健康课例、首届竞赛获奖课例思路 | 学结构与活动设计 |
| 思政素材 | 科学家事迹、本地红色资源、劳动模范故事 | 价值引领载体 |
| 心理活动素材 | 团辅游戏、训练活动、心理剧脚本 | 课堂活动备选 |
| 数据与案例 | 权威调查数据、真实教育案例 | 学情分析与说理支撑 |
| 拓展阅读 | 家长指导、教师专业阅读 | 家校协同与自备 |

## 入库标注规范（每份材料都要写清）

- **来源**：出处名称 + 链接/书刊页码
- **可用性**：可直接用于课堂 / 仅作参考 / 版权不明（不入课件）
- **关联**：用于本课的哪个环节（心思/知心/护心/心得）

## 红线

- 不下载、不使用来源不明的教材配套课件与教辅（赛事明令不得抄袭、不得复制出版社教辅课件）；
- 涉及地图、国旗、国徽的素材，必须用标准来源并注明出处（赛事红线，违反取消资格）。
