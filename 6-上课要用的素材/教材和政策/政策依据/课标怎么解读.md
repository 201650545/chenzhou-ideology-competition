## 一、本课的政策支点链条（四级递进，每级都有原文出处）

```
《纲要》具体目标"使学生学会学习和生活"          ← 总方向的合法性
        ↓
《纲要》小学中年级"初步培养学生的学习能力，      ← 本课所属学段与板块的直接依据
激发学习兴趣和探究精神，树立自信，乐于学习"
        ↓
"学会学习"板块 → 注意力管理 / 学习方法 / 时间管理   ← 《纲要》第5条六大重点之一
        ↓
本课主题：专注力（注意力控制）                   ← 心理主线
＋ 思政载体：科学家精神（探究精神的具体化身）        ← 价值线
```

**关键结论**：这条链条上每一环都能指回原文，因此"科学家精神"的融入**不是外加的思政任务，而是《纲要》中年级要求的自然延伸**——这是本课在评审中最有力的合规性论据，务必在方案阐述与说课中说出来。

## 二、课标条款 → 本课目标 映射表

| 课标条款（原文） | 本课目标 | 落点环节 |
|---|---|---|
| "初步培养学生的学习能力" | 认知目标：知道专注是可训练的能力；能力目标：掌握 2–3 种专注方法 | 护心·三关训练 |
| "激发学习兴趣和探究精神" | 思政目标：从科学家专注科研的经历中感受探究精神与专注品格 | 知心·故事建构 |
| "树立自信，乐于学习" | 能力目标：用星星自评看到自己的进步（纵向自比，不横向排名） | 护心·即时自评 |
| "增强时间管理意识" | 迁移目标：把"专注小锦囊"用到作业与阅读情境 | 心得·迁移 |
| 第 8 条"心理健康教育课应以活动为主" | 全课形态：以体验与训练为主，不以知识讲授为主 | 全流程 |
| 第 8 条"防止学科化倾向" | 不讲授心理学名词（注意力广度/稳定性等术语不进课堂语言） | 全流程禁忌 |
| 《行动计划》"五育并举促进心理健康" | 以智慧心（学习方法）+ 以劳健心（劳动与坚持的价值） | 知心 + 心得 |

## 三、合规检查清单（设计定稿前逐项过）

- [ ] 依据表述**不写"心理健康课程标准"**——本学科无独立课标，只写"纲要 + 课程方案 + 行动计划"三件套
- [ ] 课堂形态**以活动为主**（三关训练为课堂主体），非知识讲授
- [ ] 不出现心理学专业术语堆砌（防止学科化倾向）
- [ ] 教材表述符合"经省级以上教育行政部门审定的中小学心理健康教育材料"
- [ ] 课标条款引用只作依据说明，**不作口号式堆砌**（评分标准要求"潜移默化"）
- [ ] 思政目标与核心素养目标**写在一起并说明衔接关系**（对应复赛评分"教学目标 10 分"）
- [ ] 评价设计**可观察、可测评**（星星自评表 + 教师观察记录，对应"教学评价 5 分"）

## 四、可直接引用的规范表述（写进设计表 / 方案阐述）

> **依据段落模板**：依据《中小学心理健康教育指导纲要（2012 年修订）》关于小学中年级"初步培养学生的学习能力，激发学习兴趣和探究精神，树立自信，乐于学习"的要求，结合《全面加强和改进新时代学生心理健康工作专项行动计划（2023—2025 年）》"五育并举促进心理健康"的部署，本课以专注力训练为主线，将科学家的探究精神作为价值载体，实现学习能力培养与价值塑造的同频落地。

> **教材表述模板**：本课依据湖南省地方课程教材《心理健康教育》（湖南人民出版社）四年级上册"学会学习"板块设计，教学素材来源为该册【课题名待课本确认】。

> **课堂形态表述模板**：遵循《纲要》"心理健康教育课应以活动为主""防止学科化倾向"的要求，本课以情境体验、心理训练、小组讨论为主要形式，不作心理学知识讲授。
