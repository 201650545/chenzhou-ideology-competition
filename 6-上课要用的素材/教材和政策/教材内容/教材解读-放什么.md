# 教材解读

> 状态：待课本到位后撰写。前置：[[教材内容-放什么]]

## 要产出什么

1. **单元定位**：本课所在单元的主题归属（六大主题中的哪一个/哪几个）、在全册的位置
2. **编写意图**：教材为什么在这个年级、这个位置安排这一课；四板块（心思/知心/护心/心得）各自的编写功能
3. **前后衔接**：上一课学了什么、下一课要学什么，本课在能力链上承接与铺垫了什么
4. **教材处理建议**：教材活动哪些直接用、哪些替换（如把书上的活动替换为"专注三关"）、替换的理由
5. **与课标的对应**：教材内容如何承载课标要求（与本目录 README 末节的结论呼应）

## 输出格式建议

一份 `教材解读.md` + 一张"单元结构图"（该册各课一览，标出本课位置）。放在本目录下。
