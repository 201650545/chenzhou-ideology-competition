# 每个文件夹放什么

> 一句话：**原文放一处，解读放一处，来源必须留痕。**
> 上级：[[素材总说明]]

## 一、教材和政策 / 教材内容

| 文件 | 放什么 |
|---|---|
| [[四年级10课一览]] | 四年级上册 10 课的课题、所属主题、能搭配的思政点 |
| [[选教材的过程]] | 为什么最后选湘教版，其他版本为什么不选 |
| [[教材内容-放什么]] | 课本正文怎么录、版本信息怎么记 |
| [[教材解读-放什么]] | 这一课在整册里的位置、编写意图、前后课怎么衔接 |

## 二、教材和政策 / 政策依据

| 文件 | 放什么 |
|---|---|
| [[政策文件清单]] | 《纲要》《课程方案（2022）》《行动计划》的原文条款与官方链接 |
| [[课标怎么解读]] | 把政策条款翻译成课堂动作（本课的政策支点、目标映射） |
| [[政策依据-放什么]] | 这一格收什么、不收什么 |

## 三、课件和教具 / 图片视频音频 / 参考课例

| 位置 | 放什么 |
|---|---|
| `课件和教具/` | 上课用的 PPT 源文件与导出件、学具卡（兴趣卡／种子卡／星星自评表） |
| `图片视频音频/` | 课件引用的每一张图、每一段音视频，附来源、链接、版权状态、本地备份 |
| `参考课例/` | 别人的优秀课例、思政素材、心理活动设计、数据与案例 |

## 四条铁律

1. **原文层只放原文**——`教材内容`、`政策依据` 不写评论和观点，避免出处和判断混在一起。
2. **每个设计结论都要能指回具体条款**——写"因为纲要第 X 条……所以本课……"，不写"根据新课标精神"这类空话。
3. **教材内容必须记版本信息**（出版社、册次、课序、页码），比赛报名表要填"教学素材来源"。
4. **图片视频必须留出处**（来源、链接、版权状态），比赛明令不得抄袭，地图国旗国徽须用规范来源。
