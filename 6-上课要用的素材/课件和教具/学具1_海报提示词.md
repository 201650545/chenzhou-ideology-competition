# 学具 1 海报版 · 出图提示词

> 用途：生成《我的星星榜》海报式学具的**底版**，再由我把中文文字叠上去。
> 配色：**彩色版走「乙·星空探索」**（深蓝 #1B2A4A ＋ 暖黄 #FFC845 ＋ 奶油白 #FFF8EC ＋ 湖蓝 #3E7CB1）；黑白版走线描省墨路线。
> 写于 2026-09-12

---

## ⚠️ 用之前必读：为什么要"只出底版、不出文字"

图像模型画中文**必糊**（笔画会错、会缺、会变成乱码方块）。所以两条提示词里都明确要求"**不要生成任何文字**"——只出**版式、卡片、网格、星形**，标题和题目由我用代码／Word 精准叠上去。这样打印出来才清楚、才能用。

## 一、彩色版提示词（直接复制使用）

```
一张 A4 竖版（210×297mm，比例 1:1.414）的儿童心理健康课学具海报底版，面向小学四年级学生。

【主题基调】
深蓝夜空主题。深蓝 #1B2A4A 作为页面底色，暖黄 #FFC845 作为星星与点缀色，
奶油白 #FFF8EC 作为卡片底色，湖蓝 #3E7CB1 作辅助色。
扁平化设计：无渐变、无投影、无发光、无描边高光。

【版式结构】
1. 顶部约占 18%：一整条深蓝色标题横幅，横幅内只留大块空白（供后期放标题），
   横幅右下角点缀三颗大小不一的实心暖黄星。
2. 中部约占 55%：一张奶油白大圆角卡片，卡片内是 4 列 × 13 行的浅灰细网格
   （1 行表头 + 12 行课程，行高一致）。每行右侧并排三个圆形空心五角星占位，
   供学生用彩笔涂色。网格线极细（0.5px）、浅灰 #CFCFCF。
3. 底部约占 27%：三张横向奶油白圆角小卡片，等高排列，每张内部留一条长横线区域
   （供学生手写）。每张卡片左上角放一枚小的暖黄星作为序号标记位。
4. 页面四角各一颗小暖黄星作装饰。

【硬性要求】
- 所有文字位置保持空白：不要生成任何文字、字母、数字、符号或乱码。
- 星形必须是规整的五角星轮廓，线条干净；12 行课程行的星形大小完全一致。
- 留白充足，整页像一张优秀的教育海报底版，干净、现代、有呼吸感。
- 不要卡通动物、不要贴纸感、不要立体元素、不要装饰花纹。
- 输出 300dpi，A4 竖版。
```

## 二、黑白版提示词（直接复制使用）

```
一张 A4 竖版（210×297mm，比例 1:1.414）的儿童心理健康课学具海报底版，
面向小学四年级学生，将用激光黑白打印机打印。

【主题基调】
纯黑白线描风格，白底黑线，不使用任何颜色。
用线宽与灰度分层：主边框 1px 黑 #000，次级分隔线 0.5px 灰 #999，
标题区用浅灰底 #F0F0F0 反白留字，避免大面积黑底（省墨）。

【版式结构】
1. 顶部约占 18%：一个描边矩形标题区，内部为浅灰底并留大块空白（供后期放标题），
   矩形右下角点缀三颗大小不一的实心黑星。
2. 中部约占 55%：一张描边圆角矩形，内部是 4 列 × 13 行的细网格
   （1 行表头 + 12 行课程，行高一致）。每行右侧并排三个空心五角星占位，
   供学生涂黑／涂色。网格线 0.5px 中灰。
3. 底部约占 27%：三个等高描边圆角矩形，每个内部留一条长横线区域（供学生手写），
   每个矩形左上角放一枚小的空心星作为序号标记位。
4. 页面四角各一颗小空心星作装饰。

【硬性要求】
- 所有文字位置保持空白：不要生成任何文字、字母、数字、符号或乱码。
- 星形必须是规整的五角星轮廓，线条干净；12 行课程行的星形大小完全一致。
- 靠留白和线宽形成层次，保证黑白打印后依然清晰、不糊、不脏。
- 不要卡通动物、不要贴纸感、不要立体元素、不要装饰花纹。
- 输出 300dpi，A4 竖版。
```
