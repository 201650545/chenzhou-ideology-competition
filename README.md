# 第二届郴州市大中小学课程思政教学竞赛 · 参赛项目

**组别**：小学组 C 类（心理健康教育）
**课题**：湘教版《心理健康》四年级上册 第 1 课《最喜欢的课》
**参赛**：湖南省郴州市永兴县
**关键节点**：2026-09-16 校内初审交件；2026-09-16 当天课堂实录拍摄

---

## 一、一页看懂：这节课在讲什么

| 项 | 内容 |
|---|---|
| 主线 | **承认有不喜欢，并学会对待它** |
| 核心问题 | 为什么要学不喜欢的课 |
| 心理层（80%） | 接纳"我有不喜欢的课"这个真实感受，不装、不躲 |
| 价值层（15%） | 每门课都有它的用处 → 正确学科观 |
| 思政落点（5%） | 德智体美劳**全面发展**，在此之上发展**个性** |
| 铁律 | 价值必须**从学生嘴里出来**，老师不喊口号、不讲授（防学科化） |

## 二、课堂结构（40 分钟 · 六环节）

| # | 环节 | 时长 | 学习单 | 说明 |
|---|---|---|---|---|
| 一 | 我的课表星星榜 | 5′ | 正面 | 前测：12 门课涂星 |
| 二 | 一样的课表，不一样的星星 | 3′ | — | 引出主题 |
| 三 | 喜欢，是有理由的 | 8′ | 正面 | 说理由，分类板书 |
| 四 | **假如没有这门课……** | 12′ | 反面 | **高潮，不可砍** |
| 五 | 我的两个小行动 | 7′ | 反面 | 迁移应用 |
| 六 | 今天，我最大的发现 | 5′ | 反面 | 后测 · 收口 |

**模式**：活动体验式（暖身 → 体验 → 分享 → 升华迁移），对标常规课的"导入 → 新授 → 巩固 → 小结"，但**把"讲授"换成学生"做"**。
